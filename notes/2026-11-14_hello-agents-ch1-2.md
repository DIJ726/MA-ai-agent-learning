## 一、第 1 章：什么是智能体（Agent）

### 1.1 定义
**Agent（智能体）**：以大语言模型为"大脑"，能够感知输入、自主规划步骤、调用外部工具、并在多轮循环中推进直到完成目标的软件系统。

一句话区分：
- **普通 LLM 调用**：你问一句，模型答一句，结束。（今天的 `llm_demo.py` 就是这一类）
- **Agent**：给定一个目标，模型自己决定"下一步做什么、要不要调工具、结果够不够"，循环执行直到任务完成。

### 1.2 Agent 的四个基本特性（经典 AI Agent 理论）
| 特性 | 含义 | 在我们项目里对应 |
|------|------|----------------|
| 自主性 Autonomy | 不需要人逐步指挥，自己驱动流程 | 第 3 周手写 ReAct 循环 |
| 反应性 Reactivity | 能根据环境/工具返回的结果调整下一步 | Observation 回到 Thought |
| 主动性 Proactiveness | 不只被动应答，会主动规划、推进任务 | Plan-and-Solve 规划阶段 |
| 社交性 Social Ability | 能调用工具、与其他 Agent/系统交互 | Function Calling、MCP（第 4 周） |

### 1.3 Agent 的常见类型
- **按数量**：单 Agent（一个大脑）/ 多 Agent（分工协作，如研究 + 写手 + 审核，第 6 周 CrewAI）
- **按形态**：
  - **AI Native Agent**：模型自主推理决策（本教程主线，第 3 周手写的就是这种）
  - **工作流平台**：Coze / Dify / n8n，用可视化节点拼固定流水线，模型只填其中节点
- **按任务**：对话助手、工具调用型、研究型、代码型（Codex/Cline 这类）

### 1.4 三个经典范式（第 4 章会手写，先记名字）
| 范式 | 核心思路 | 一句话 |
|------|---------|--------|
| **ReAct** | Reason + Act 交替：思考 → 行动 → 观察 → 再思考 | 边想边做，最基础 |
| **Plan-and-Solve** | 先把任务拆成计划，再逐步执行 | 先规划后动手 |
| **Reflection** | 执行后自我批判、反思、重试改进 | 做完回头检查 |

### 1.5 应用场景
客服问答、代码助手、数据分析、研究检索、自动化办公、多工具串联的工作流……判断标准：**任务是否需要模型在过程中自主选择动作**。需要 → Agent；固定一问一答 → 普通 LLM 调用即可。

## 二、第 2 章：智能体发展史

理解历史是为了看清"今天的 Agent 为什么长这样"。

### 2.1 符号主义（早期 AI，1950s–1980s）
- 思路：把人类知识和推理规则写成显式规则（if-then），机器按规则推导。
- 代表：**专家系统**（如早期医疗诊断、棋类程序）。
- 局限：规则靠人手写，覆盖不了开放世界；知识稍一变就要改规则。

### 2.2 连接主义 / 机器学习（1990s–2010s）
- 思路：不手写规则，从数据里学统计规律。
- 代表：统计机器学习 → **深度学习**（神经网络、感知机堆叠）。
- 进步：模式识别（图像、语音）大幅提升；但模型只能做单轮预测，缺少通用语言推理和自主决策能力。

### 2.3 LLM 驱动的智能体（2020s 至今）
- 大模型具备了通用语言理解、推理、代码生成和**指令遵循**能力，可以充当统一的"推理内核"。
- Agent = **LLM 大脑 + 工具调用 + 记忆 + 规划循环**：
  - 工具（Function Calling / MCP）：让模型能操作外部世界
  - 记忆（对话历史 / 向量库）：跨轮次保留上下文
  - 规划循环（ReAct 等）：把"思考—行动"串成自主流程
- 对比符号主义：规则不再手写，改由模型从语言与训练中学得；对比深度学习单轮预测：LLM Agent 能多轮自主决策并调用工具。

### 2.4 演进主线图
```
符号主义（专家系统/规则）
   → 机器学习（统计模型）
      → 深度学习（神经网络）
         → 大语言模型（通用推理内核）
            → LLM Agent（大脑 + 工具 + 记忆 + 规划循环）
```

## 四、易混点 / 面试话术

- **聊天机器人 ≠ Agent**：关键分界是"是否自主选择动作并调用工具完成目标"，不是有没有对话界面。
- **Agent 不是新模型**：Agent 是一种**系统架构**，模型是其中的大脑；同一个 LLM 可以只做对话，也可以包成 Agent。
- **工作流平台 ≠ AI Native Agent**：前者流程由人画死，后者由模型在运行时自主决策下一步。
